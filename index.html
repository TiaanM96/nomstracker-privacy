NomsTracker Privacy Policy

Last updated: 16 November 2026

NomsTracker is an independently developed browser extension for tracking NomStead timers, map resources, inventory counts, and in-game wealth changes. For privacy questions, contact tiaan.myburgh@gmail.com.

Independent tool: NomsTracker is not affiliated with, endorsed by, or sponsored by NomStead or its developers.

Information NomsTracker reads

When you use NomsTracker on nomstead.com, it reads game-page information already available in the browser to provide its features. This may include land names and links, crop and processor types, timer dates, nearby resource details, inventory totals for Items, Objects, and Recipes, and visible game message text used by optional timer controls and to add or reset a recurring pond timer after fishing. The message text is processed locally and is not sent to a NomsTracker server.

When you use the processor quick-add control, NomsTracker reads the visible processor queue entry's tool or recipe name, processing status, and displayed remaining time so you can save a matching timer. This information is processed locally. NomsTracker does not start, stop, or otherwise control the processor.

The optional Wealth tracker reads the current Gold coin balance (the game's user.balance field), Silver coin balance (user.silver), and Gold bar count (user.goldBarCount). Currency snapshots are saved only after you choose Start tracking in the Wealth tab. The tracker records observed changes over 30-day periods. It may not capture transactions that happen and cancel out between observations.

NomsTracker also stores the settings, timer records, custom labels, and land details you create. It does not request your NomStead password. It does not submit game actions or automate gameplay. Saved tile links are ordinary links and are followed only after you click them. Optional browser notifications are created by the browser extension; operating-system notification settings determine how banners are displayed.

Storage and synchronization

Extension records are stored in browser extension storage on your device. If Edge extension sync is enabled and available, NomsTracker writes a compact copy to Edge sync storage so Microsoft Edge can synchronize it across signed-in devices. Depending on the features you use, synchronized records can include timers and land links, settings, saved tool-land links, inventory tracker snapshots, and Wealth tracker balances and observed changes. Microsoft Edge provides this synchronization.

NomsTracker does not operate a separate developer-hosted account or data server and does not send these records to a NomsTracker analytics endpoint. NomsTracker's interface uses locally packaged icons. The NomStead website may independently load its own game content and images.

Retention and controls

Inventory changes are tracked in 14-day periods, and Wealth changes in 30-day periods. The Wealth tracker starts only after you opt in. Timer and land records remain until you remove them, clear extension storage, or remove the extension. You can export or import a backup in Settings and manually reset Inventory and Wealth periods. Synced copies may remain on another device until Edge synchronizes or that device's extension data is cleared.

Policy page hosting

The provider hosting this policy page may process basic technical request information under its own privacy practices. This is separate from NomsTracker's handling of extension data.

Changes to this policy

This policy will be updated if NomsTracker changes the information it reads, stores, or synchronizes. The version linked from an Edge Add-ons listing should match the extension's current behavior.
